# 层合固化证据台

本地可重放的复合材料层合板固化证据应用，使用 Java、Spring Boot、SQLite 和服务端 SVG。它把设计铺层、实际铺放、材料批次、炉程规范、热电偶时序、真空/压力记录和人工操作关联到同一炉次证据。

## 构建与运行

```bash
mvn -q -DskipTests package
mvn -q test
mvn -q spring-boot:run -Dspring-boot.run.arguments=--server.port=5557
```

访问：

```text
http://127.0.0.1:5557
```

页面标题为“层合固化证据台”。SQLite 默认写入 `data/cure-evidence.db`；首次启动且数据库为空时自动导入固定 fixture。也可点击页面上的“清空并重新导入”，或调用 `POST /api/reset` 删除当前业务数据并重新导入。

## 固定 fixture

固定数据位于：

```text
src/main/resources/fixtures/fixed-fixture.json
```

- 规范版本：`CURE-SPEC-7.3`
- fixture 版本：`FIX-2026.1`
- 炉次：`RUN-CFRP-20260922-A`
- 8 层预浸料，铺层方向为 `0/45/-45/90/90/-45/45/0`
- 3 支必需热电偶：`TC1`、`TC2`、`TC3`，保温中 `TC3R` 替换 `TC3`
- 保温允许带：闭区间 `175°C ≤ T ≤ 185°C`
- 共同连续保温要求：1800 秒
- `175°C` 与 `185°C` 样本均按合格处理

fixture 的输入摘要和 SHA-256 写入 `runs` 表；每次评估在 `evaluations` 中保留规范版本、输入摘要、总判定和评估时间，在 `rule_results` 中保留每条规则的证据区间、说明和失败时间范围。

## 数据口径

保温时间按以下规则计算：

1. 必需传感器在同一时间点都有当前有效样本时，才形成“共同帧”。
2. 共同帧温度必须全部位于规范闭区间；刚好等于上下限也算合格。
3. 共同连续保温从所有当前必需传感器首次同时合格的时间点开始。
4. 任一当前必需传感器离开允许带时，当前连续段立即中断。
5. 不同连续段分别计时；任一段达到 1800 秒才合格，不能把各传感器各自达标时间相加，也不能把被中断的多个片段相加。
6. 传感器替换后，替换件接管同一控制点槽位；替换发生在两个共同帧之间也强制分段。
7. 时钟回退、重复样本和传感器替换都是证据链边界，不允许跨边界拼成一段保温。
8. 待确认的传感器异常或替换记录会在证据链规则中形成失败时间范围；人工确认后保留分割事实，但不再作为“待确认”失败。

固定 fixture 的共同保温结果：

- `10:35–10:40`：三支原热电偶共同在带，300 秒，随后时钟回退/重复样本分割。
- `10:50`：`TC3` 出现 211°C 异常样本。
- `10:53`：`TC3R` 替换 `TC3`，证据强制分段。
- `10:55`：`TC3R=174°C`，共同帧尚不合格。
- `11:00–11:25`：替换后的三支当前传感器共同在带，1500 秒。
- 两个片段均不足 1800 秒，因此保温规则失败，总判定为 `NONCONFORMING`；`11:15` 的 185°C 边界样本合格。

## 页面与接口

页面提供：

- 铺层堆叠、设计/实际方向、材料批次和操作者追溯
- 热电偶曲线、175–185°C 允许带、异常和替换事件
- 炉程阶段、真空和压力阈值
- 每条规则的证据段、证据区间和失败时间范围
- 确认传感器异常/替换记录
- 选择部件控制点
- 建立偏差处理分支
- 操作审计、运行记录导出、清空并重新导入

主要 API：

```text
GET  /api/bench
GET  /api/chart.svg
GET  /api/stack.svg
GET  /api/export
POST /api/sensor-events/{eventId}/confirm
POST /api/control-points/{pointId}/select
POST /api/deviations
POST /api/reset
```

导出的 JSON 是一次完整运行记录快照，包含输入、评估结论、规则段、失败范围、人工操作和偏差分支，可用于离线复核。

## 自动化测试

```bash
mvn -q test
```

测试覆盖：

- 三支热电偶错位到温后才开始共同保温
- 175°C 和 185°C 闭区间边界合格
- 时钟回退、重复样本和传感器替换强制分割
- 多个片段不相加，固定 fixture 最长共同段不足 1800 秒
- 页面标题、SVG、API、异常确认、控制点选择、偏差分支、导出和清空重导入
